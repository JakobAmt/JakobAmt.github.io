Astromech Voice Assistant

An interactive voice assistant inspired by R2D2 Astromech Droid.

Voice Recognition Natural Language Processing Python APIs Raspberry Pi Electronics

A AI-powered voice assistant built inside a 22cm tall 3D-printed custom astromech model, running on a Raspberry Pi 5. The project combines hardware electronics, mechanical design, and AI APIs to create a desktop companion that responds to voice commands, displays animations, and reacts to its requests with lights and sound.

For the 3D printed design it was done by using a finished model from Printables: R2D2 Astromech Droid Link. The model however has been modified by me to have a servo mount inside the head, and holes for RGB Diodes and USB-C connector. Additional parts were also added for mounting the Raspberry Pi and speaker.

System Flowchart

• The raspberry pi is listening for the wakeword: "Hey R2"
• Thens plays a sound effect when wakeword is detected, then starting to listening for a command or question.
• Using Text-to-Speech (TTS) and sends the question to Gemini API
• Gemini sends a response over to ElevenLabs Voice Text to Speech API
• Finally, the systems plays the response audio through the speaker.

Other Functions of the Astromech

• Responds to any type of question or request with the gemini
• Plays random sound effects when the wakeword is detected
• Displays animations on a 0.96" OLED screen
• Different LED light patterns based on the status of the system
• Rasberry hosts a local website for monitoring and control
